# 云五笔（CloudWubi）五笔输入法软件 —— 软件说明书

## 一、软件概述

| 项 | 内容 |
|---|---|
| 软件名称 | 云五笔（CloudWubi）五笔输入法软件 |
| 版本 | v0.5.51 |
| 开发语言 | Java（Android） |
| 运行环境 | Android 7.0 及以上 |
| 安装包 | 99.9KB |
| 开源许可 | MIT |

**功能定位**：一款支持 86 版五笔、五笔拼音简拼混打、云端 AI 联想、计算器、剪贴板、中英翻译的轻量级输入法，安装包小于 100KB，完全开源免费。

## 二、主要功能

### 1. 五笔输入（核心）
- 标准 86 版五笔规则：字根字、一级简码（25 键）、二级简码、三级简码、全码
- 词组按官方规则编码：二字词=前2+前2、三字词=首+首+前2、四字及以上=一二三末首码
- 最近上屏字/词自动置顶（MRU 规则），越用越顺手

### 2. 拼音与简拼混打
- 输入拼音全拼或简拼（首字母）也能出候选
- 五笔编码与拼音自动识别，无缝混打

### 3. 云端 AI 联想（腾讯云 SCF 网关）
- 12 万+ 词组云端词库，实时更新热点词
- 上下文连续联想（顺承联想表）
- 高频字词统计与推送
- 网络不可用时自动降级为本地词库（离线可用）

### 4. 内置计算器
- 数字+运算符实时出结果，支持连续计算（1+2=3*4=12）
- 可带公式上屏或仅结果上屏

### 5. 智能剪贴板
- 复制文本自动记录历史，点选上屏
- 长按删除、防误操作（取消恢复）

### 6. 中英互译
- 端侧常用词 + 云端 12 万词典 + 机器翻译三层兜底
- 翻译结果可点击上屏

### 7. 英文自动补全
- 邮箱后缀、网址（ht→https://）、.com 等自动补全

### 8. 键盘面板
- 主键盘（26 键）、数字面板（九宫格+运算）、符号面板（最近/中文/英文/emoji/网络分类）
- 上滑输入符号、深色/浅色跟随系统主题、扁平 FLAT 风格

### 9. 状态栏/备选栏
- 状态栏：云五笔、编码、英文翻译
- 备选栏：MRU 置顶 + 传统五笔高频 + 云端热点词

## 三、操作说明

### 1. 安装与启用
1. 下载 CloudWubi.apk（GitHub/Gitee Releases）
2. 安装后进入系统设置 → 语言与输入法 → 键盘 → 管理键盘 → 启用"云五笔"
3. 切换输入法为"云五笔"即可使用

### 2. 基本输入
- 直接按键输入五笔编码（a~y 25 键）
- 候选出现后点选上屏；空格键上屏首选
- 回车键：中文候选上屏 / 英文直接上屏

### 3. 大小写切换
- 上档键单击切换大小写；连按两次锁定大写

### 4. 数字与符号
- 点"123"进入数字面板，可实时计算
- 点"符"进入符号面板，分类浏览（最近/中文/英文/emoji/网络）
- 键盘上滑输入符号（如"！""？"）

### 5. 剪贴板
- 复制任意文本后，点工具栏"亖"查看历史
- 点选条目上屏；长按条目删除；"◀ 返回"关闭

### 6. 翻译
- 输入词后，状态栏显示英文翻译
- 点击翻译可上屏

### 7. 工具栏
- 全选⭕️：选中当前文本框全部内容
- ✕：退格删除
- ↺ 取消 / ↻ 重做
- 亖：剪贴板
- 🔽：收起键盘

## 四、技术说明

| 模块 | 说明 |
|---|---|
| 输入法框架 | Android InputMethodService |
| 词库引擎 | 端侧精简词库（单字 6500+/词组 4200+，离线可用）+ 云端 12 万+ |
| 云端网关 | 腾讯云 SCF（Python），端点：编码查询/词组/拼音/联想/翻译/热词 |
| 翻译 | 词典 + 腾讯 TMT + 百度翻译三层 failover |
| 排序 | MRU 置顶 > 一级简码 > 高频 > 云端热点 |
| 构建 | 命令行脚本（aapt2+javac+d8+固定签名），APK ≤100KB 硬门禁 |
| 隐私 | 本地处理，无收集上传；云端查询不含个人身份信息 |
