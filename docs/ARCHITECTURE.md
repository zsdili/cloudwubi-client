# 云五笔架构

## v0.5.36 架构原则（固化）：云端优先，前端薄

**核心原则：能改后端就不改前端，避免用户频繁下载安装。**
1. **词库/联想/排序/热词全部云端化**：客户端只保留最小离线兜底（基础字库+词组+动态拼词）
2. **前端只负责交互与渲染**：键盘布局、候选展示、剪贴板、计算器面板
3. **变更分级**：
   | 变更类型 | 通道 | 用户影响 |
   |---|---|---|
   | 词库/热词/拼音/排序 | 云端 SCF 部署 | 无感（无需更新） |
   | 交互/布局/面板 | 客户端发版 | 需下载新 APK |
4. **云端能力清单**：五笔编码查询（2.6万字库）、动态构词、分类词 31 类 7659、拼音全拼/简拼、高频字排序、每日热词、英文翻译、连续联想
5. **默认策略**：新功能优先评估云端实现，云端不可行（需本地键盘交互）才走客户端
