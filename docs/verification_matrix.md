# 云五笔 · 50 场景真机回归矩阵（v0.5.63 起每版发布前必测）

> 固化机制：每版发布前，真机按此矩阵逐项测试；通过项打 ✅，未通过项必须修复后再发布。
> 配套《验证环境声明》（docs/verification_declaration.md）说明各场景由"代码级"还是"真机级"保证。

## A. 计算类（7）
| ID | 场景 | 操作步骤 | 预期结果（正确） |
|---|---|---|---|
| A1 | 删除重输不粘连 | 2×3=6 上屏 → 全选删除 → 再输 2×3 | 得 2×3=6（**不得** 22×3） |
| A2 | 连续运算续算 | 1+2=3 上屏 → 再输 *4 | 得 1+2=3*4=12（**不得** 33*4） |
| A3 | 结果后继续减 | 2+5=7 上屏 → 再输 -4 | 得 7-4=3（**不得** 77-4） |
| A4 | 除法续算 | 8*4=32 上屏 → 再输 /16 | 得 32/16=2（**不得** 3232/16） |
| A5 | 结果保留续算界面 | 2+3=5 上屏后 | 保留当前输入界面，可继续加/删运算符计算 |
| A6 | 带式/不带式两种上屏 | 运算结果出现候选 1.带式 2.仅结果 | 两种均可点选上屏 |
| A7 | 实时出结果 | 输入 2+3 尚未按等号 | 备选栏实时显示 1.2+3=5 2.5 |
