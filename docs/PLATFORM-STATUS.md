## macOS 版声明

**状态**：官方签名分发已**暂停**（源码与自编译路径保留）。

**原因**（诚实声明）：
1. macOS 13+ 系统仅接受"有开发者身份签名"的第三方输入法（Rime/鼠须管、vChewing 等正式分发项目均为此模式）；
2. 获取分发签名需加入 Apple Developer Program，年费 **$99（中国区 ¥688）**；
3. 该项目秉持**免费开源、贡献全网全人类**的初心，年费门槛与"无需宣传营销、靠口碑自传播"的价值观冲突，故暂停官方分发。

**自编译路径**（任何人可用，免费）：
```bash
# 1. 安装免费 Xcode（App Store 下载）
# 2. 克隆仓库
git clone https://github.com/zsdili/cloudwubi-client.git
cd cloudwubi-client/macos
# 3. 本机构建（Development 签名，本机可用）
bash build_local.sh
# 4. 安装
bash install.sh build/CloudWubi.app
# 5. 注销重登 → 系统设置 → 键盘 → 输入法 → + → 云五笔
```

**恢复条件**：若未来获得社区捐赠/众筹支持（覆盖 ¥688/年），将恢复官方签名分发。

## iOS 版声明

**状态**：未启动，官方放弃（暂定）。

**原因**：
1. iOS 第三方键盘仅能通过 App Store 分发（无侧载），需 $99 账号；
2. 中国区上架还需 App 备案等额外合规流程；
3. 与免费开源初心冲突。

**恢复条件**：同 macOS——获得社区资助后评估。

## 核心原则（固化）

- **免费开源优先**：不向用户收取任何费用；
- **代码永远开放**：任何人可获取源码自编译、自用、共建；
- **口碑自传播**：不依赖宣传与营销；
- **贡献值驱动**：向全网全人类贡献智慧与力量。
