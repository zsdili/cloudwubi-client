# 云五笔 · 真机 50 场景回归矩阵（发布强制门禁）

> 铁律：**每版发布前，以下 50 场景必须逐项真机验证并打勾**（用户实测或用户确认后由我代录）。
> 任一项 ❌ → **禁止发布**。任一项 ⚠️（偶发/异常）→ 记录复现步骤，修复后再发。
> 本矩阵是"F（真机环境）"的唯一权威来源——逻辑测试/模拟器通过**不视为通过**。

## 使用说明
- 每版编号：`vX.Y.Z` 发布时复制本表为 `docs/verification/vX.Y.Z.md` 打勾存档。
- 状态：✅ 通过 / ❌ 失败（禁止发布）/ ⚠️ 偶发（记录步骤）/ ⛔ 不适用（说明原因）
