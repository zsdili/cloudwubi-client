## 闭环纪律（写死）
1. 每轮发布前：本台账 🔄/❌ 项逐项核查 → 未闭环禁止发版
2. 每轮开发：只做 ≤3 项新功能，其余资源全给闭环
3. 用户反馈新问题 → 先入台账（根因分析），再排期，不重复口头承诺
